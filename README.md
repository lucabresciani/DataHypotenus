# DataHypotenus

Il database personale della casa: cosa possiedo, dove sta, quanto è costato, se è ancora in
garanzia, quali documenti ha, e cosa manca ancora. Applicazione locale, offline, senza cloud.

## Versioni

| Cartella | Cos'è |
|---|---|
| [`light/`](light/) | La versione leggera: CSS scritto a mano con design token, nessuna dipendenza grafica, nessun font remoto. Un processo Node, un file SQLite. |

Ogni cartella è un progetto completo e autonomo: istruzioni, documentazione e test stanno
dentro la cartella. Per partire: [`light/README.md`](light/README.md).
